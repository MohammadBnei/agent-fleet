# Architecture Decision Records

One file per real decision — a competing alternative existed, a choice was
reversed, or a live incident forced a change. Format: Status / Date /
Context / Decision / Consequences. Status is one of `Proposed`, `Accepted`,
`Rejected`, `Superseded`.

Decisions with no real alternative ever on the table live in
[`../DECISIONS.md`](../DECISIONS.md) §1 instead, not here.

| [0050](0050-a-question-outlives-its-pod.md) | A blocking `AskUserQuestion` survives pod teardown and warm — it returns `{"status":"pending"}`, the turn ends, the pod is free to idle-reap, and the human's answer (a durable `answer` row) is delivered to the **next** pod on warm via the same `streamHumanMessages` replay every human message uses, fed in as a labeled input turn. `ReserveSlot`'s stale-close now spares `question` rows (closing only `permission_request`, whose allow/deny buttons are bound to a dead pod's `canUseTool` promise), because auto-answering the question on warm would destroy the exact answer the human was about to give.
